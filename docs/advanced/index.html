    runtime/All modules

    All modules as a table

    How it was made. python -m tools.dev.code_map reads every .c, .cpp and .h file in runtime/src and runtime/include. A file and its header count as one module (gpu.c + gpu.h = gpu). Between modules, a line means one includes the other's header or names a function defined there. Between functions, a line means one names the other in its body: a call, or passing it as a function pointer. Calls through pointers at run time and calls inside macros are not seen. Not shown: the recompiled game code (made on your own computer at build time), shaders, the launcher and the Python tools.
